6. สิ่งที่เห็นจากตาราง: ข้อแตกต่างของทั้ง 3 ตัว

6.1 แต่ละตัวเก่งคนละด้าน ไม่มีตัวไหนจับครบ

Snyk

จุดแข็ง: ตัวเดียวที่ครบทุกประเภท (SAST, SCA, IaC, container) และเห็น CVE ใน base image

จุดอ่อน: SAST จับโค้ดได้น้อยสุด (5/12) และพลาด SQL injection ซึ่งเป็นช่องโหว่พื้นฐานที่สุด

Aikido

จุดแข็ง: จับ pattern ที่เสี่ยงได้กว้าง เช่น eval, dangerouslySetInnerHTML, redirect และการอ่านไฟล์ (8/12)

จุดอ่อน: พลาด command injection ซึ่งร้ายแรง ให้ SSRF แค่ Medium และแผนฟรีไม่สแกน container / IaC

GHAS

จุดแข็ง: วิเคราะห์ data flow ฝั่ง server ได้ลึก ไล่ input ไปถึงคำสั่งอันตรายจริง จับ command injection, SSRF, ปิด TLS และ SQLi (8/12)

จุดอ่อน: พลาด path traversal, dangerouslySetInnerHTML, server redirect และไม่มี container / IaC เลย

6.6 จุดบอดร่วมของทั้ง 3 ตัว

ไม่มีตัวไหนจับ hardcoded password "SuperSecret123!" ได้ และ unit test ด้าน security จับ SQL injection ได้ทั้งที่ Snyk พลาด scanner จึงแทน test ไม่ได้ ยังต้องมี security regression test และ secret scanner ที่จับรหัสผ่านทั่วไป (เช่น gitleaks)

7. สรุปและข้อเสนอ

ถ้าเลือกตัวเดียว
  • Aikido: จับโค้ดได้มากสุด (เท่า GHAS) ติดตั้งง่ายสุด comment อ่านง่าย แต่แผนฟรีไม่มี container scan และต้องปรับเกณฑ์เป็น High
  • GHAS: data flow ลึก (command, SSRF, TLS) ฟรีสำหรับ public แต่ไม่มี IaC/container และ private repo ต้องซื้อ
  • Snyk: ครบทุกประเภท (SAST, SCA, IaC, container) เด่นสุดเรื่อง container แต่ SAST จับในเดโมนี้ได้น้อยสุด (พลาด SQLi)
ถ้าใช้คู่กัน
  • Aikido + GHAS ครอบคลุมโค้ด 11/12 จุด แต่ยังขาด container
  • Snyk + GHAS ครอบคลุมโค้ด 9/12 + container + IaC
  • ทุกแบบยังต้องมี unit test ด้าน security และ secret scanner ที่จับรหัสผ่านทั่วไป (เช่น gitleaks / Semgrep secrets) เพราะไม่มี tool ไหนจับ "SuperSecret123!"
